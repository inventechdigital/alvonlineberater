OnlineBerater Native Embed Test

Verwendung (Native Embed)

Diese Variante mountet das Widget direkt in ein DIV-Element und übernimmt die Styles der Host-Seite:

<!-- Mount Point -->
<div id="onlineberater"></div>

<!-- Embed Script -->
<script src="https://alvonlineberater.lovable.app/onlineberater-embed.js"></script>

Farben anpassen

Sie können die Farben über CSS-Variablen überschreiben:

.onlineberater-container {
  --ob-primary: 220 70% 50%;        /* Blau statt Türkis */
  --ob-gradient-start: 220 80% 40%;
  --ob-gradient-end: 260 60% 50%;
}
