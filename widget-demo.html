OnlineBerater Widget Demo

Verwendung

So binden Sie das Widget in Ihre Website ein:

<!-- Widget Script einbinden -->
<script src="https://alvonlineberater.lovable.app/onlineberater-widget.js"></script>

<!-- Widget verwenden -->
<online-berater></online-berater>

Build-Anleitung

  1. Projekt zu GitHub exportieren
  2. Lokal klonen: git clone [repo-url]
  3. Dependencies installieren: npm install
  4. Widget bauen: BUILD_TARGET=widget npm run build
  5. Die Datei dist-widget/onlineberater-widget.js auf Ihren Server hochladen
